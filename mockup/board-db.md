# 팀 게시판 Dataverse 스키마

[화면 목업](board.html)의 글 등록·조회·수정·삭제에 사용할 Dataverse 테이블을 정의합니다.

## 게시글 테이블

- 표시 이름: **게시글**. 스키마 이름: `<prefix>_BoardPost`.
- `<prefix>`는 선택한 비관리형 Solution의 실제 Publisher 접두사입니다. `$set-pp`가 기록한 Solution과 접두사를 실제 환경에서 확인해 사용합니다.
- 글 하나를 행 하나로 저장합니다. 이 화면에 필요한 데이터는 게시글 테이블 하나에 둡니다.

| 항목 | 스키마 또는 논리 이름 | 형식 | 입력 규칙 |
|---|---|---|---|
| 게시글 ID | Dataverse가 생성한 기본 키 | GUID | 자동 생성 |
| 제목 | `<prefix>_Title` | 한 줄 텍스트, 최대 100자 | 필수. 테이블의 기본 이름 열 |
| 내용 | `<prefix>_Body` | 여러 줄 일반 텍스트 | 선택. 빈 값 저장 가능 |
| 작성일 | `createdon` | 시스템 날짜 및 시간 | Dataverse가 등록 시 기록 |

## 앱에서 쓰는 방식

- **등록** — 제목과 내용의 앞뒤 공백을 제거합니다. 제목이 비어 있거나 100자를 넘으면 등록을 막습니다. 저장에 성공하면 입력란을 비우고 목록을 갱신합니다.
- **목록·상세 조회** — 목록은 제목과 본문 미리보기, 작성일을 `createdon` 기준 최신순으로 표시합니다. 항목을 선택하면 상세 모달에서 제목·전체 본문·작성일을 보여줍니다.
- **수정** — 상세 모달에서 기존 제목과 내용을 편집합니다. 등록과 같은 검증을 적용하고, 선택한 게시글 ID의 행만 수정합니다. 작성일은 유지하며 저장 뒤 상세와 목록을 갱신합니다.
- **삭제** — 상세 모달에서 삭제를 선택하면 확인 메시지를 표시합니다. 확인한 경우 선택한 게시글 ID의 행만 삭제하고, 성공하면 모달을 닫고 목록을 갱신합니다. 취소하면 데이터를 바꾸지 않습니다.

## Codex 구현 기준

1. [프로젝트의 Dataverse 스키마 Skill](../vendor/power-platform-skills-codex/plugins/dataverse/skills/dv-metadata/SKILL.md)에 따라 지정한 Solution을 확인합니다. 같은 테이블이 있으면 열 형식과 기본 이름 열을 확인해 재사용합니다.
2. 테이블을 Canvas 앱의 데이터 원본으로 추가하고 연결된 실제 이름과 열 형식을 확인한 뒤 화면을 구현합니다. 수정·삭제 대상은 화면의 제목이 아니라 Dataverse 기본 키로 식별합니다.
3. 테스트 글을 등록한 뒤 목록에서 열어 전체 본문을 확인합니다. 같은 행의 수정 결과가 목록과 상세에 반영되는지 확인하고, 테스트 글만 삭제한 뒤 재조회에서 사라지는지 확인합니다.
